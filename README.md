# Souvenir design duel

Static side-by-side picker for the runner-souvenir layouts.

## GitHub Pages
1. Push the contents of this folder to a repository (root or `/docs`).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)`.
3. Open the published URL — `index.html` is the picker.

All files are static: no build step, no dependencies.

## Contents
- `index.html` — pairwise comparison app
- `support.js` — runtime it loads
- `designs/` — one file per layout, plus `designs/assets/`
